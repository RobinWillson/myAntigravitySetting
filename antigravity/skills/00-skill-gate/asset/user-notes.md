# User Notes (技能備註備份)

此檔案為使用者手寫技能筆記之主要備份檔。
當您執行更新技能指令時，AI Agent 會自動從此處與 `global-skill-list.md` 讀取手寫筆記並進行雙向同步，絕不會覆蓋您在此處撰寫的內容。

請依照以下格式撰寫或維護您的技能筆記（以技能名稱作為 `##` 二級標題）：

## 00-skill-gate
在此寫下您對 00-skill-gate 的手寫備忘或特殊設定說明。

## find-skills
在此寫下您對 find-skills 的補充說明。

## mcp-chrome
- 設定於 mcp_config.json 之中。
- 用以替代原本 Graves/chrome-devtools。

## gstack
- 很複雜的 Skill, 還沒測試過
- 文件中似乎也說了要安裝很多依賴, 有用到的時候再研究

## skill-creator
- 任何建立技能的動作發生時, 務必觸發

## gog
- Windows 桌面環境下，若已登入，Windows 憑證管理員會自動處理憑證解密，一般免去設定 GOG_KEYRING_PASSWORD 環境變數。

## chrome-extension-standard
在此寫下您對 chrome-extension-standard 的手寫備忘或特殊設定說明。
